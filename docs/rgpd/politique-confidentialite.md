# Politique de confidentialité — brouillon

Ce document est un gabarit de travail, pas une politique publiée. Les coordonnées légales,
la liste finale des sous-traitants, les bases légales, les transferts et les durées doivent être
validés par le DPO ou le conseil juridique avant mise en production.

IDEL OS traite uniquement les données nécessaires à la préparation administrative et à
l’organisation de l’activité. Aucune donnée identifiante patient n’est envoyée à un LLM.
